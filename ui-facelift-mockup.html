Design notes for review

  • Logo: Pensive marks — P in coin, thoughtful P, leaning stack, seed penny, wordmark.
  • Design system: reusable tokens + components in design-system/ (palettes, spacing, cards, heroes, lists, chip tabs, period cards).
  • Pages: Home / Monthly / Payables / Chat / Settings are mocked. No Compare page; summary and insights stay folded into Home.
  • Appearance: Settings opens as a hub; Appearance is a drill-in for Theme (Light/Dark) + palettes. Graphite remains default; Ocean, Azulejo, Dusk, Graphite, and Slate are selectable.
  • Hero: desktop fans Safe to spend / Money in / Money out; phone keeps swipe + dots. Copy uses “this fortnight” (Elly).
  • Home: scope switcher; fortnight cards; categories + trends; recurring bills + expenses split.
  • Monthly v2: progressive rows (check·name·amount; pay-to/♻/drag on select), phone period tabs, action dock (Done/Move/Pay to/More), long-press menu, auto-open Money In when overspent.
  • Payables: owing hero; Mine/Eric owner switch in the app bar (same pattern as Home scope); account filter + All/Shared/Solo chips; account-grouped open sections; add form; allocation modal; completed disclosure.
  • Chat: full nav page inspired by production expanded mode — searchable history, new chat, receipt attach, composer, thinking state, and proposed-action confirm cards.
  • Settings: Salary and Pay To accounts are grouped in the hub. Admin actions are marked owner-only via html[data-role="owner"] so the Elly/Eric demo toggle can hide them.
  • IA: Home = overview. Scope switch is Home-only.
  • Phase 0 defaults (prod path): drop Compare; keep Home simplified (no full Insights/Summary restore); Chat stays a nav page; ship propose_payable first; Eric copy uses “this month” where period framing differs.
  • Phase 1: Monthly Pay To + Move modals, Payables Edit sheet, Chat receipt preview + proposal saving state — no toast-only dead ends on those flows.
  • Phase 2 / 3A: design-system safe-area + contrast hardened; production Admin now has Appearance (theme/palette) wired to tokens.css.
  • Production app is untouched — this is exploration only.
